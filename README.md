# RoMulti-RobloxInstance

RoMulti adalah pengelola instance Roblox untuk Windows x64. Jalankan RoMulti.exe untuk melihat instance dan mengatur role Main atau AFK Saver. Kontrol window, pengelolaan handle, penghematan RAM, dan system tray tersedia di jendela utama.

Pilih **Dark** atau **Light** di bagian atas jendela. RoMulti menyimpan tema untuk akun Windows yang sedang dipakai.

Untuk membuat `RoMulti.exe` dari source, jalankan perintah ini di folder repo:

    powershell -ExecutionPolicy Bypass -File .\build.ps1
